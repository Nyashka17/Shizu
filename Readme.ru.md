## Что вы получаете

| Возможность | Что она делает |
| --- | --- |
| Модули | Установка по ссылкам или файлам, просмотр каталогов репозиториев, настройка модулей и управление псевдонимами. Поддерживаются несколько публичных и приватных репозиториев. |
| Веб-панель | Настройка Shizu, управление модулями, просмотр логов, скачивание и восстановление зашифрованных резервных копий. Доступ к браузеру требует одобрения владельцем аккаунта. |
| Панель управления в Telegram | Откройте `/panel` в вашем боте для управления запуском, префиксом, токеном бота и панелью. |
| BeSafe | Проверка стороннего кода перед загрузкой. Карточки одобрения приходят в отдельный чат; опасные запросы к аккаунту блокируются по умолчанию. |
| Инлайн- и расширенные сообщения | Формы, галереи, кнопки и расширенная вёрстка для модулей. |
| Резервные копии | Зашифрованные резервные копии базы данных с настраиваемым ежедневным расписанием и отдельным ключом восстановления. |
| Языки | Английский, русский и узбекский для интерфейса, с переведёнными настройками модулей. |

Shizu использует **Pyrogram** и поддерживает **Telethon** через опциональный отдельный вход.
Включите его во время настройки или с помощью `.enabletlmode`; `.disabletlmode` отзывает сессию.
Сессии Telethon зашифрованы, с ключом, сгенерированным автоматически или предоставленным через
`SHIZU_SESSION_KEY`.

## Установка

### Linux и macOS

```bash
git clone https://github.com/ibeswipin/Shizu
cd Shizu
bash install.sh
```

Инсталлятор использует `uv` для подготовки Python 3.11 и виртуального окружения, устанавливает
Shizu и проводит вас через вход в Telegram. Существующая конфигурация и сессии
используются повторно.

Запускайте его от имени обычного пользователя. Вам понадобятся **Git** и **curl или wget**. Если
зависимости требуют компиляции, установите инструменты сборки вашей платформы.

В Linux с systemd инсталлятор может создать службу, которая запускается от вашего имени.
Настройка службы требует `sudo` и происходит только после успешного входа. Существующий
`shizu.service` сохраняется; держите репозиторий по тому же пути после установки.

<details>
<summary><b>Ручная установка</b></summary>

При установленном Git и Python 3.11:

```bash
git clone https://github.com/ibeswipin/Shizu
cd Shizu
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install .
python -m shizu
```

</details>

<details>
<summary><b>Команды запуска и службы</b></summary>

| Команда | Назначение |
| --- | --- |
| `bash install.sh --no-start` | Установка зависимостей без входа или настройки службы |
| `bash start.sh` | Запуск Shizu вручную |
| `sudo systemctl restart shizu` | Перезапуск службы Linux |
| `journalctl -u shizu -f` | Отслеживание логов службы |

## Первый запуск

Откройте URL настройки, выведенный в консоли. Страница веб-настройки доступна через
туннель localhost.run.

1. Введите свой **API ID** и **API Hash** из [my.telegram.org/apps](https://my.telegram.org/apps).
2. Отсканируйте QR-код в Telegram: **Настройки → Устройства → Привязать устройство desktop**. Можно также войти по номеру телефона.
3. Введите свой **пароль двухфакторной аутентификации**, если он есть.
4. Дайте Shizu создать бота, или укажите токен вашего бота.

После настройки Shizu перезапускается и публикует свой статус в **Shizu-logs**.
Используйте `.help` в обычном чате или в **Shizu-Expiriments**, чтобы начать.

| Флаг запуска | Назначение |
| --- | --- |
| `--no-web` | Использовать вход через консоль |
| `--port 8080` | Установить порт веб-настройки |
| `--setup-only` | Войти и выйти без запуска пользовательского бота |

## Команды

Префикс по умолчанию — **`.`**. Измените его с помощью `.setprefix` или через `/panel`.

| Команда | Назначение |
| --- | --- |
| `.help` / `.help <модуль или команда>` | Просмотр модулей и справки по командам |
| `.dlmod` / `.dlmod <имя или ссылка>` | Просмотр каталогов репозиториев или установка модуля |
| `.loadmod` | Установка модуля из файла, на который вы ответили |
| `.unloadmod <имя>` | Выгрузка модуля |
| `.config [модуль]` | Открыть настройки модуля |
| `.web` / `.web stop` | Открыть панель управления или закрыть её и отозвать сессии браузера |
| `.restart` / `.update` / `.stop` | Перезапустить, обновить или остановить Shizu |
| `.checkupdate` | Проверить наличие новых коммитов без их установки |
| `.setprefix <префикс>` / `.setbot <токен>` | Изменить префикс команды или токен бота |
| `.lang [код]` | Выбрать язык интерфейса |
| `.backupdb` / `.restoredb` | Создать или восстановить резервную копию базы данных |
| `.autobackup` / `.backupkey` | Включить/выключить ежедневные резервные копии или показать путь к ключу восстановления |
| `.besafe` / `.apiprotect` | Просмотреть решения BeSafe или включить/выключить защиту от flood API |
| `.owner [пользователь]` | Открыть панель владельцев или добавить/удалить владельца |
| `.alias [псевдоним] [команда]` | Список, добавление или удаление псевдонимов команд |
| `.info` | Показать вашу карточку информации о Shizu |

Отправьте **`/panel`** своему боту, чтобы открыть его панель управления.
Время ежедневной резервной копии настраивается в `.config ShizuBackuper`.

## Ваша папка Shizu

Shizu создаёт папку чатов **Shizu**, содержащую вашего бота и эти группы:

| Чат | Назначение |
| --- | --- |
| Shizu-logs | Логи, статус запуска и отчёты об ошибках |
| Shizu-backup | Зашифрованные резервные копии базы данных |
| Shizu-besafe | Карточки одобрения модулей и подтверждения безопасности |
| Shizu-Expiriments | Сообщения, команды и эксперименты с модулями |

Пока Shizu запущен, сообщения пользователей автоматически удаляются из Logs,
Backups и BeSafe перед запуском команд или наблюдателей. Сервисные сообщения и кнопки
одобрения остаются доступными. Используйте **Shizu-Expiriments** для своих сообщений и команд.

## Восстановление резервной копии

Резервные копии базы данных шифруются перед отправкой в Telegram. Ключ восстановления
создаётся при первом резервном копировании по адресу `~/.config/shizu/backup.key`, вне репозитория
и базы данных. `.backupkey` показывает его путь без отправки самого ключа.

**Храните отдельную копию ключа.** Чтобы восстановить на другом сервере, скопируйте
оригинальный ключ туда сначала. `SHIZU_BACKUP_KEY_FILE` позволяет выбрать другой путь к файлу ключа.
